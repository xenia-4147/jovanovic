<product_requirements>
The user requires a digital business card application compatible with all major platforms (Android, Apple, phone contacts, WhatsApp, email, websites). Key features include:
1.  **Card Creation & Customization**: Name, company, position, website, multiple phone numbers and email addresses (with labels and primary designation), social media links (Instagram, LinkedIn, Twitter, TikTok, Telegram), profile picture, logo upload, a creator's note/description, privacy settings (public/private), and extensive color customization (background, text, accent, embedding colors).
2.  **Sharing & Compatibility**: QR code generation, Airdrop, Bluetooth (with potential for even better possibilities), direct vCard (.vcf) download, and embedding on websites.
3.  **Advanced Features**: Direct call/message/WhatsApp/email links from the card, an auto-update system for data changes (notifying recipients), addresses with Google Maps navigation, an alphabetized, collapsible address book view (displaying profile picture, logo, name/company), and a custom sharing code for each card.
4.  **Privacy**: Backend must be GDPR-compliant.
5.  **Design**: Modern, individually adjustable, responsive design for all devices, and a distinct, compact view for external users resembling a phone contact list entry.
</product_requirements>
